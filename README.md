# WordPress Misconfiguration & Website Defacement

## Project Overview

A hands-on cybersecurity lab project performed using Linux
inside Oracle VirtualBox.

The project focuses on understanding WordPress security
misconfiguration, reconnaissance, enumeration, security
assessment, privilege management and website defacement
within a controlled laboratory environment.

## Environment

- Linux
- Oracle VirtualBox
- WordPress
- Linux Terminal
- Nmap
- WPScan
- Dirb
- Metasploit

## Project Areas

1. Network Scanning
2. Service Enumeration
3. Directory Enumeration
4. WordPress User Enumeration
5. Vulnerability Assessment
6. Security Testing
7. Privilege Escalation Concepts
8. Website Defacement Simulation
9. Security Hardening
